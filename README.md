# ICOFEA 2026 Website

A responsive static conference website for ICOFEA 2026.

## Files
- `index.html` — all conference content and links
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, countdown, copy-button and reveal effects
- `assets/` — official conference flyer, MAsREE logo crop and QR crops

## Publish
Upload the entire folder to Netlify, GitHub Pages, Cloudflare Pages, cPanel hosting or any static web host.

## Important content to approve before public launch
1. President's Message is a drafted placeholder and should be replaced with the official approved message, name and portrait.
2. Verify that the registration and abstract QR redirect URLs still resolve to the intended live forms.
3. Confirm publication outlet wording and any publication charges/selection criteria with the organising committee.
4. Add programme, keynote speakers, organising committee and edutrip itinerary when finalised.
