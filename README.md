# ICOFEA 2026 Website

This package is ready for GitHub Pages.

## Live structure
- `index.html` — full-screen ICOFEA 2026 montage landing page
- `home.html` — main conference website
- `assets/icofea-montage.mp4` — integrated 10-second montage video

## GitHub Pages
Upload all files and folders in this directory to the root of the `icofea2026` repository.

Expected public URL:
https://icofea.github.io/icofea2026/

The montage autoplays muted because modern mobile and desktop browsers commonly block autoplay with sound. Visitors can tap **Sound on** and can enter the main site at any time using **ENTER SITE**.

## Responsive montage videos
The landing page now automatically switches videos:
- Desktop/tablet (768px and wider): `assets/icofea-montage.mp4` — landscape 16:9
- Mobile (767px and narrower): `assets/icofea-montage-mobile.mp4` — portrait 9:16

The switch happens automatically; visitors do not need to choose a version.
